# GetFranchise Workspace Map

This folder is organized around four working areas:

- `franchise-intel/`: source data and Python report generation.
- `output/franchises/`: generated franchise reports, exports, source ledgers, and the SQLite database.
- `GetfranchiseAi/`: local browser UI and preview server.
- `docs/`: project planning, workspace notes, and original planning material.

## Run Paths

- Start the UI from the repo root with `run-local.bat`.
- Start the generator with `python franchise-intel/generate_reports.py`.
- Rebuild or query the database from `output/franchises/`.
